# PS4 Stream — PIN Edition v0.3

Chrome-расширение, сервер для Render и HTML5-плеер для PlayStation 4. **Адрес PS4 всегда один:** https://ps4-stream.onrender.com/ . После отправки фильма Chrome показывает четырёхзначный **одноразовый код**, который надо ввести на PS4. Уникальных публичных URL больше нет.

> Рабочий прототип: протестированы API, PIN, защита от повторного использования, получение ссылок в адаптере. **Не проверено на настоящей PS4 или на конкретном зеркале HDrezka.** Прямые MP4/кодеки/браузер PS4 могут оказаться несовместимы; отсутствие прямого доступа из PS4 к CDN это расширение не исправляет.

## 1. Обновить существующий Render

**Важно: сервер на Render должен быть обновлён до v0.3. Одно только обновление расширения не заработает со старым сервером v0.2.** В момент подготовки обновления по адресу https://ps4-stream.onrender.com/ ещё была страница старой версии.

1. Распакуй ZIP и скопируй содержимое `ps4-stream-render-v0.3` **в корень репозитория** своего проекта в GitHub, обновив `render.yaml`, `server/` и `extension/`. Не добавляй секретные ключи в GitHub.
2. Сохрани/отправь изменения в ветку, из которой Render развёртывает Web Service `ps4-stream`. Render может выполнить деплой автоматически, или нажми **Manual Deploy → Deploy latest commit**.
3. В Render → Environment оставь прежний `API_KEY` (или задай свой длинный случайный ключ). `TV_KEY` больше не используется — можно удалить. Параметры Web Service: Root Directory `server`, Start Command `python app.py`; в Blueprint они прописаны в `render.yaml`.
4. Открой **https://ps4-stream.onrender.com/**. Должна появиться новая страница **«Ввод кода»** с четырёхзначным полем. `/healthz` должен вернуть `{"ok":true}`.

**Адрес Render жёстко задан** в `extension/config.js`:

```js
const PS4_RENDER_ORIGIN = 'https://ps4-stream.onrender.com';
```

Он не редактируется в настройках Chrome. У тебя должен быть доступ к **именно этому** сервису на Render. Для другого Render-сервиса нужно вручную изменить константу в коде расширения и перезагрузить его.

## 2. Установить расширение

1. Chrome → `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное расширение» → папка `extension` из нового ZIP. Если была v0.2, удали старую или отключи её, чтобы не было двух кнопок.
2. Нажми иконку расширения. В поле **API_KEY** вставь ключ из Render → Environment; нажми «Сохранить ключ». URL Render в настройках фиксированный.
3. Нажми **«Тестовый ролик»**: увидишь 4 цифры. На PS4 открой `https://ps4-stream.onrender.com/`, введи PIN, нажми «Начать просмотр».
4. На HDrezka-подобной странице фильма нажми квадратную **to PS4** (слева от кнопки скачивания Helper в `.b-post__social_holder_wrapper`). Выбери качество и при необходимости субтитры → **Отправить** → на PS4 открой постоянный адрес и введи PIN.
5. Если смотришь с субтитрами, в настройках разреши загрузку HTTPS-субтитров; без этого видео отправляется, а субтитры могут пропускаться с предупреждением.

## 3. Альтернативные домены

В настройках есть поле **«Дополнительные зеркала HDrezka»**. Введи, например, `https://rezka-mirror.example/films/123.html` или просто `rezka-mirror.example`, нажми «Добавить», подтверди разрешение Chrome и обнови страницу зеркала.

- Домен добавляется только с HTTPS и только после твоего разрешения.
- Путь (`/films/...`) не нужен: скрипт будет работать на всех страницах этого домена, но кнопку покажет только на страницах с `.html` и нужным блоком Helper.
- Список можно редактировать/удалять. Стандартные домены: `hdrezka-fly.net`, `hdrezka.ag`, `rezka.ag`, `rezka.fi`, `rezka-tv.org` (с поддоменами).
- Новый домен не гарантирует работоспособность парсера: структура страниц может отличаться.

## 4. Как работает PIN

- Браузерное расширение генерирует случайный PIN из **ровно четырёх цифр**, включая начальные нули.
- Только расширение, знающее **API_KEY**, может отправить PIN и данные фильма на `POST /api/launch`.
- В серверной памяти находится **одна ожидающая отправка**. Повторная отправка заменит предыдущий PIN (предыдущий перестанет действовать).
- PS4 отправляет PIN обычной формой `POST /` и получает HTML-плеер по **тому же постоянному адресу** `/`. Успешный PIN сразу становится недействительным.
- На PS4 устанавливается HttpOnly/Secure cookie, позволяющий перезагрузить плеер в течение 10 минут. Кнопка **НОВЫЙ КОД** открывает чистую форму.
- Код действителен **10 минут с отправки**; уже загруженная страница плеера не удаляется при истечении этого срока. Ограничение попыток: не более 7 неверных за 10 минут на клиентский IP плюс общий лимит, что снижает, но не исключает риск подбора четырёхзначного PIN.
- Сессии хранятся **в оперативной памяти одного процесса**. При рестарте, бесплатном засыпании Render или деплое коды и временные cookie-сессии пропадают. Данные видео и субтитры не передаются другим пользователям через уникальную ссылку; но 4-значный PIN — не полноценная защита доступа.

## 5. Важные ограничения

- Видео воспроизводится напрямую CDN → PS4. Render отдаёт только HTML и данные. Если источник проверяет IP/Referer/cookies, если ссылка истекает или браузер PS4 не поддерживает кодек/формат, фильм не запустится или прервётся.
- На PlayStation нельзя удалённо открыть браузер обычным веб-запросом. Заход на Render и ввод PIN выполняются вручную.
- Render Free засыпает после 15 минут без входящих запросов; последующее пробуждение может быть медленным. Полученная и уже воспроизводимая HTML-страница на PS4 не зависит от Render при прямом доступе к CDN.
- Четырёхзначный PIN уязвимее длинного ключа: не используй это приложение как приватное мультипользовательское видеохранилище. Не публикуй `API_KEY`.
- Субтитры SRT/VTT загружаются расширением и встраиваются текстом; ASS/SSA и защищённые потоки без поддержки.
- Используй только контент, на доступ и воспроизведение которого у тебя есть необходимые права.

## Структура

- `extension/` — Chrome MV3, интерфейс, адаптер, управление зеркалами и генерация кода.
- `server/app.py` — стандартная библиотека Python, API отправки, PIN-форма и сессии.
- `server/player.html` — HTML5-плеер с паузой, ±10 секунд, таймлайном, временем, субтитрами, fullscreen и кнопкой нового кода.
- `render.yaml` — Blueprint Render.
- `tests/` — API-тесты и тесты парсера.

## Проверить локально (для разработчика)

```bash
python -m unittest discover -s tests -p 'test_*.py' -v
node tests/test_adapter.js
```

Перед реальным просмотром сначала попробуй «Тестовый ролик», чтобы отдельно проверить доступность Render и совместимость PS4 с HTML5 MP4.
