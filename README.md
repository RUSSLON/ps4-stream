# PS4 Stream — Render Edition v0.2 (MVP)

Новая версия расширения Chrome и облачный Python-сервер для Render. **Никакого Native Messaging и локального сервера на ноутбуке.** Видео воспроизводится PS4 **напрямую из исходного CDN**, Render только передаёт HTML-плеер и ссылки.

> Прототип без реального тестирования на PS4/HDrezka. MP4/браузер/источник могут оказаться несовместимы; DRM, HLS/DASH, требование Referer/cookie и истёкшие CDN-ссылки не обходятся.

## 1. Развёртывание на Render

1. Создай **свой** репозиторий GitHub и загрузи в него **содержимое этой папки** (включая `render.yaml` в корне). **Не публикуй ключи** в репозитории.
2. Зайди на https://dashboard.render.com, выбери **New → Blueprint** и подключи созданный GitHub-репозиторий. Render должен прочитать `render.yaml` и создать бесплатный Web Service. Если предпочитаешь вручную: **New → Web Service**, Root directory `server`, Runtime Python, Build Command `echo ready`, Start Command `python app.py`, plan Free, health check `/healthz`.
3. В разделе Render → **Environment** задай два разных длинных, случайных значения:
   - `API_KEY` — **секрет для отправки из расширения**, хранится в настройках Chrome и Environment, но не в JS-коде расширения.
   - `TV_KEY` — **секрет для персонального адреса PS4**, например `f4N_8gNsuELJiEe9vZPjz7...`. Публичный адрес строится из защищённого отпечатка этого ключа, чтобы в нём не было специальных символов. Не делай сам ключ коротким.
   В режиме Blueprint значения этих переменных создаются автоматически (`generateValue: true`); если их невозможно скопировать из интерфейса Render, переопредели их на свои и сохрани.
4. Дождись успешного развёртывания и скопируй адрес своего сервиса вида `https://my-ps4-stream.onrender.com`. Тест: `/healthz` должен вернуть `{"ok":true}`.

Сгенерировать ключи локально (Python установлен только **для генерации ключей**, не нужен для запуска расширения):

```bash
python -c "import secrets; print('API_KEY=', secrets.token_urlsafe(32)); print('TV_KEY=', secrets.token_urlsafe(32))"
```

Можно использовать любой генератор криптографически стойких случайных строк. Не отправляй ключи никому.

## 2. Chrome

1. Открой `chrome://extensions`, включи «Режим разработчика», затем «Загрузить распакованное расширение» и выбери папку `extension`.
2. Нажми иконку **PS4 Stream** в Chrome. Вставь адрес своего Render и `API_KEY`, нажми **Сохранить**.
3. Для проверки связи нажми в настройках **Отправить тестовый ролик**. Это откроет готовую страницу с коротким публичным MP4 без парсера; так проще отдельно проверить Render и PS4.
4. Если хочешь субтитры, отдельно нажми **Разрешить загрузку субтитров**. Это запрашивает широкое HTTPS-разрешение, нужное потому, что ссылки на субтитры бывают на разных CDN. Разрешение необязательно — без него видео отправится, а субтитры будут пропущены с предупреждением. Неизвестные/неподдерживаемые источники не добавляются в автоматические разрешения.
5. Зайди на поддерживаемое зеркало HDrezka (список в `extension/manifest.json`), выбери серию, перевод и качество через **to PS4**, отметь субтитры и нажми **Отправить**.
6. Chrome покажет персональную ссылку, например `https://my-ps4-stream.onrender.com/tv/24-символьный-код`. Именно эту ссылку открывай на PS4 и добавляй в закладки. При следующем фильме ссылка будет **та же самая**.

**Важно:** PS4 открывает страницу **самостоятельно** (автоматического запуска браузера консоли извне нет). Если открыть ссылку до отправки видео, страница ожидания обновляется каждые 20 секунд. Плеер продолжит работу после закрытия Chrome на ноутбуке, если исходный видеосервер допускает прямой доступ с PS4.

## 3. Ограничения Render и безопасности

- Free Web Service засыпает через **15 минут без входящих запросов** и просыпается от нового запроса (обычно около минуты). При засыпании или деплое **данные сессии в памяти теряются**, но открытая ранее страница с прямым видео не нуждается в работающем Render для дальнейших запросов к CDN.
- Сессия доступна для загрузки на PS4 **10 минут после каждой отправки**; уже открытая страница не закрывается. По истечении 10 минут отправь из Chrome ещё раз, если требуется обновление страницы.
- Сервис хранит ровно **одно последнее видео** в памяти, пока не истекут 10 минут или не произойдёт перезапуск. При новом фильме содержимое постоянной ссылки обновляется. Это однопользовательский прототип: одновременно смотреть разные фильмы через один Render нельзя.
- Любой, кто узнает полную персональную ссылку `/tv/персональный-код`, сможет смотреть текущее содержимое и увидеть прямую видеоссылку через исходный код страницы. Держи её приватной. `API_KEY` должен быть известен только тебе.
- Само видео **не проходит через Render**, поэтому расход исходящего трафика Render минимален. Однако иногда видеоссылки завязаны на IP/Referer/cookie или требуют неподдерживаемых кодеков. Эти проблемы решаются отдельно, **Render их не устраняет**.
- Источник может отдавать ограниченные по времени ссылки, которые перестанут работать при перемотке/продолжении воспроизведения. 10 минут *не означают*, что фильм полностью загрузился в буфер PS4.
- Субтитры загружаются браузерным расширением перед отправкой и встраиваются в HTML как текст. Неудачная загрузка не мешает воспроизведению видео. Простые SRT/VTT поддерживаются; расширенная разметка ASS/SSA нет.
- HTTPS-сайт Render не предоставляет удалённое управление самой PS4 или возможность принудительно открыть браузер PS4.
- Используй видео, на которое у тебя есть права доступа, и соблюдай условия сервиса.

## Структура

- `extension/` — Chrome MV3 расширение, кнопка, адаптер HDrezka, настройки Render, отправка.
- `server/app.py` — только стандартная библиотека Python, POST `/api/launch`, GET `/tv/<TV_KEY>`, GET `/healthz`.
- `server/player.html` — самодостаточная страница для PS4: play/pause, ±10, таймлайн, таймер, fullscreen, субтитры.
- `render.yaml` — Render Blueprint для бесплатного Web Service.
- `tests/` — тесты.

## Локальные тесты (не требуются пользователю PS4)

```bash
python -m unittest discover -s tests -p 'test_*.py'
node tests/test_adapter.js
```

## Что ещё надо реально проверить

1. Как именно HDrezka Helper возвращает рабочие прямые ссылки на твоём зеркале при выборе сезона, перевода и серии.
2. Открывается ли **прямой MP4** (желательно H.264/AAC) в браузере PS4 через Render.
3. Не блокирует ли CDN видео для PS4 по IP/cookies/Referer.
4. Корректно ли браузер PS4 рисует субтитры и fullscreen.

Если PS4 не играет видео, проблема может быть в прямой ссылке, а не в Render. Диагностировать надо на коротком свободном тестовом MP4 и по очереди проверять кодек, URL, заголовки и срок действия токена.
